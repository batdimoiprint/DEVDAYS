# Cue-pid

Cue-pid is a playful matchmaking prototype that turns names into fictional love teams and stories. It is designed for entertainment, whether you are matching two people or pairing a group of friends.

## What it does

- **Duo:** Enter two names to generate a ship name, a compatibility score, a three-part story, and playful details such as confessions, flags, and a hashtag.
- **Match the Room:** Enter a list of names to pair everyone up. If there is an odd number of people, the remaining person joins the Third Wheel Hall of Fame.
- **Share the fun:** Copy a match summary, save the illustrated portrait as a PNG, or generate a 24-second trailer in Duo mode. Trailer downloads depend on browser recording support.
- **Choose your experience:** Switch between Taglish and English, and turn the generated music on or off.

The results are generated from the names for fun; they are not a real measure of compatibility.

## Try the prototype

Open [`cue-pid.html`](./cue-pid.html) directly in a modern browser. No installation is needed for the standalone prototype.

## Project setup

The repository also contains a Next.js starter application. To run it locally:

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000). The Next.js app currently shows the starter page; the Cue-pid prototype is the separate HTML file.
