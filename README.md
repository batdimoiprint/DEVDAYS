# Cue-pid

Cue-pid randomly selects one of three pairs: Gehlee and Jeo Ong, Queen Leng and Xander Ford, or Kara David and Dinorobong Tubo. The two wheel pointers show the selected pair.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Match videos

The match modal plays `public/gehlee-jeo.mp4` for Gehlee and Jeo Ong and `public/queen-leng-xander-ford.mp4` for Queen Leng and Xander Ford. Kara David and Dinorobong Tubo show a waiting message until their video is added. The page does not call the retained Veo API.
